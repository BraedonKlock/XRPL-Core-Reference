# XRPLD C++ Reference

Explore the C++ internals of rippled, the XRP Ledger's core server implementation.

XRPLD C++ Reference is a searchable, navigable reference for the C++ implementation of the XRP Ledger in [XRPLF/rippled](https://github.com/XRPLF/rippled). It documents the internal classes, functions, types and relationships on the `develop` branch for developers contributing to rippled. It is not documentation for the public JSON-RPC or WebSocket APIs.

This is an unofficial, independently maintained reference. It is not affiliated with or endorsed by the XRPL Foundation, Ripple, or the rippled maintainers.
